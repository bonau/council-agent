## Translator (matrix v2)

| Tier | Risk | Grant | Interaction intent |
|------|------|-------|--------------------|
| 0 | any | not required | force ConfirmMode (incl. read) |
| 1 | read | not required | not required |
| 1 | mutate | valid→auto; not found→ConfirmMode; revoked/expired/insufficient→deny | as above |
| 1 | high_risk | not required | ConfirmMode after step-up |
| 2 | any | valid if match else not required | auto after authority |

CLI default `--trust-tier 0`. Library `SecurityContext` / `run_council` default Tier 1 for ConfirmMode.COMPAT compatibility. Matrix bumped to v2 so read risk may carry interaction.
