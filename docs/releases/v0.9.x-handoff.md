# v0.9.x → v1.0-alpha 交接追蹤

> 供後續 Agent 接手。每完成一版更新本表與 `learning-log-v1-prep.md`。  
> **停止線：v1.0-alpha 前**（不開 Trust Tier runtime change）。

## 規則

1. **一版一 PR**：`cursor/v09N-<name>-d691` → base `develop`；驗收通過才 merge。
2. 每個 patch 對應一個 OpenSpec change；完成後 sync → validate → archive。
3. 發版：`release/0.9.N` 只做版本 bump（`pyproject.toml` + `__init__.py`），merge `main` + tag，再 `--no-ff` 回 `develop`。
4. 合併前必過：`./scripts/check.sh`。
5. 每版追加學習紀錄；更新本表狀態。

## v0.9.1 交接狀態

- Runtime／regression evidence：[`v0.9.1-shell-containment-evidence.md`](v0.9.1-shell-containment-evidence.md)；V1-001／V1-002 已在 implementation revision 關閉。
- Compatibility break：raw `python`、`uv run`、shell interpreter、未知 executable、compound shell、expansion 與未建模 options 現在 fail-closed；pytest 走 typed `run_tests`。
- Release branch 待辦：只有 `release/0.9.1` 可更新 `pyproject.toml` 與 `src/council_agent/__init__.py`，兩處需一致；本 feature branch不得 bump 或 tag。
- v0.9.2 仍從 `policy-middleware`／唯一 dispatcher／`SecurityContext` 開始。不得把 v0.9.1 的 shell-local prepared action helper 宣稱成統一 middleware。
- v1.0-alpha Trust Tier runtime、`council trust` 與 tier CLI 仍是停止線後工作，v0.9.x 不提前實作。

## v0.9.2 交接狀態

- Runtime／regression evidence：[`v0.9.2-policy-middleware-evidence.md`](v0.9.2-policy-middleware-evidence.md)；SEC-P0-002／V1-003 已由唯一 `invoke()`、單一 `SecurityContext` lifecycle、direct／Crew bypass tests 與 315-test regression 關閉。
- Public library breaking change：六個 public tools 需要 active `SecurityContext`；缺少／closed／stale context 回傳 structured refusal，不再 ambient fail-open。直接 caller 使用 `SecurityContext.create(...)` + `security_context(...)`。
- CrewAI adapters 不再接 tracker/session，也不做 limit/session/audit；middleware 是唯一 evidence writer。Sandbox 每個 action 產生一個 tracker summary、一個 session line與 attempt/result 兩筆 audit。
- 無 sandbox 仍套用 context/workspace/policy/confirmation/limit 並保留 in-memory summaries，但沒有 durable session/audit；不能把 audit 空檔解讀成沒有 action。
- `policy_version="v0.9-unversioned"` 只是 snapshot label。v0.9.3 必須接續 `policy-trust-boundary`，處理 project policy restrict-only trust boundary、versioned schema 與未知欄位 fail-fast，不得在 v0.9.2 偷做。
- v0.9.4 audit integrity、v0.9.5 principal、v0.9.6 authentication、v0.9.7 grant、v0.9.8 decision matrix 與 v1.0-alpha Trust Tier runtime 均未提前實作。
- Release branch 待辦：只有 `release/0.9.2` 可更新 `pyproject.toml` 與 `src/council_agent/__init__.py`，兩處需一致；本 feature branch不得 bump 或 tag。
