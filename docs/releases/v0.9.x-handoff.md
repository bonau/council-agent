> 供後續 Agent 接手。每完成一版更新本表與 `learning-log-v1-prep.md`。  
> **停止線：v1.0-alpha 前**（不開 Trust Tier runtime change）。

## 規則

1. **一版一 PR**：`cursor/v09N-<name>-d691` → base `develop`；驗收通過才 merge。
2. 每個 patch 對應一個 OpenSpec change；完成後 sync → validate → archive。
3. 發版：`release/0.9.N` 只做版本 bump（`pyproject.toml` + `__init__.py`），merge `main` + tag，再 `--no-ff` 回 `develop`。
4. 合併前必過：`./scripts/check.sh`。
5. 每版追加學習紀錄；更新本表狀態。

## 單一 patch 標準作業（給下一個 Agent）

1. `git checkout develop && git pull && git checkout -b cursor/v09N-<change>-d691`
2. OpenSpec：`npx @fission-ai/openspec@latest new change "<change>"` → proposal／design／specs／tasks（**Non-goals 必寫**）
3. 依 tasks 漸進實作；每階段 `uv run pytest`
4. sync delta → `validate --specs --strict` → archive → `./scripts/check.sh`
5. push 分支；用 `ManagePullRequest` 開 PR（base `develop`）
6. 驗收通過後：`bash scripts/release-patch.sh cursor/v09N-<change>-d691 N "<summary>"`
7. 更新本表與 learning-log；**停止於 v1.0-alpha 前**（勿開 Trust Tier runtime）
