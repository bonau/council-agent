## 正向與 canonical-action evidence

- [`test_run_command_submits_resolved_argv_with_shell_false`](../../tests/test_shell_containment.py) 斷言 exact argv list、retained executable、quoted whitespace boundary 與 `shell=False`。
- [`test_run_command_gate_order_is_fixed`](../../tests/test_shell_containment.py) 斷言 `cwd → analysis → path operands → canonical policy → confirmation → execution`，且 policy／execution 使用同一 action。
- [`test_required_path_commands_execute_inside_workspace`](../../tests/test_shell_containment.py) 真實執行 `cat`、`ls`、`rm`、`mv`、`cp`、`touch`、`mkdir`，涵蓋 nested cwd、相對與絕對路徑。
- [`test_path_beginning_with_dash_executes_after_double_dash`](../../tests/test_shell_containment.py) 證明 `--` 後的 `-note` 被當成 path operand。

## Refusal／bypass／無副作用 evidence

- [`test_parser_refusals_never_start_subprocess`](../../tests/test_shell_containment.py) 涵蓋未知 executable、malformed quote、`;`、`|`、`&&`、backtick 與 `$()`；每個結果都有 stable `rejection_reason`、無 `exit_code`、subprocess call count 為 0。
- [`test_policy_denial_precedes_confirmation_for_canonical_action`](../../tests/test_shell_containment.py) 證明 deny 不能由 confirmation 旁路，且拒絕前不 prompt、不執行。
- [`test_external_sentinel_read_is_refused`](../../tests/test_shell_containment.py) 對 `cat` 與 `python` 的工作區外 sentinel read 都斷言拒絕、sentinel 不變、subprocess call count 為 0。
- [`test_external_destination_is_refused_without_side_effect`](../../tests/test_shell_containment.py) 與 [`test_one_invalid_operand_refuses_entire_multi_source_action`](../../tests/test_shell_containment.py) 證明 outside `cp`／`mv` destination 或 mixed valid/invalid operands 不會部分執行。
- [`test_traversal_and_symlink_escape_leave_external_sentinel_unchanged`](../../tests/test_shell_containment.py) 斷言 traversal／symlink escape 都是 `workspace_boundary`，外部 sentinel 不變。
- [`test_compound_syntax_has_no_file_process_or_network_side_effect`](../../tests/test_shell_containment.py) 涵蓋 `;`、`&&`、`||`、pipeline、redirect、newline、backtick、`$()` 與帶 network-capable executable 的 compound input；marker 不存在且沒有 process／network launch。
- [`test_inherited_environment_value_cannot_be_expanded`](../../tests/test_shell_containment.py) 證明 `$SENTINEL_PATH` 不會由 inherited environment 展開。

## `run_tests` smoke evidence

- [`test_run_tests_preserves_path_and_quoted_arg_boundaries`](../../tests/test_shell_containment.py) 斷言空白路徑保持一個 argv element，`-k "test with spaces"` 保持一個 value，並以 `shell=False` 執行。
- [`test_run_tests_executes_typed_special_character_path`](../../tests/test_shell_containment.py) 真實執行名稱含空白、Unicode、引號、`;`、`$()` 與 backtick 的 pytest 目錄，結果 `1 passed`、exit code 0。
- [`test_run_tests_metachar_args_are_refused_without_side_effect`](../../tests/test_shell_containment.py) 涵蓋 args 中的多命令、pipeline、redirect、newline、backtick 與 substitution，皆無 marker／subprocess。
- [`test_run_tests_policy_precedes_confirmation_and_execution`](../../tests/test_shell_containment.py) 及 [`test_run_tests_is_write_classified_and_confirmation_can_refuse`](../../tests/test_shell_containment.py) 證明 typed test action 仍經 policy、明確 `write` classification 與 confirmation。
