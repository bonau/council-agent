# v1.0 Beta 公開測試手冊

> 狀態：**公開 beta 基線已 tag**；Agent 代跑證據見 `docs/releases/evidence/v1.0.0-beta.1/`（ACCEPTED GATE A）。固定基線 tag：`v1.0.0-beta.1`（package `1.0.0b1`）。Alpha 基線為 `v1.0.0-alpha.1`。獨立真人 TTY 留待下一 beta；LIVE-01 需可用 provider key。

## 1. 安全警告

- `run_command` 使用受限 simple-command grammar、canonical argv、`shell=False`；**不是** OS sandbox。
- Trust Tier：`council run --trust-tier {0,1,2}`（CLI 預設 0）。`--yes` 只跳過互動，不是 Tier 2。
- Tier 2 需要 principal `high-risk:manage` 與 `COUNCIL_AUTH_SECRET` fresh step-up。
- Exact trust grants 可在 Tier 1 跳過 mutate 確認；project policy **不能**設定 tier 或提權。
- Audit 有 redaction／sequence／per-event ID；**沒有** predecessor-linked／external hash chain。

**禁止**在含真實秘密或正式資料的目錄測試。

## 2. 隔離需求

使用一次性非特權環境、暫存 workspace、outside sentinel；預設停用外連；LIVE-01 需 release lead 核准。

## 3. 安裝

從固定 beta tag／wheel 安裝，記錄版本與 SHA-256：

```bash
python -m pip install "council-agent==1.0.0b1"
council --help
```

或自本 repo 的 `v1.0.0-beta.1` checkout 執行 `uv sync`。

## 4. 必跑案例

1. SMK-00～SMK-09（[`smoke-suite.md`](smoke-suite.md)）
2. Tier 向量：Tier 0 read refuse／auto；Tier 1 grant skip；Tier 2 無 verifier fail-closed；`--yes` 不提權
3. MAN-01～MAN-14（[`manual-test-cases.md`](manual-test-cases.md)）
4. LIVE-01：僅經核准

結果只填 `PASS`／`FAIL`／`BLOCKED`／`NOT-RUN`。證據目錄：`docs/releases/evidence/v1.0.0-beta.1/`。
